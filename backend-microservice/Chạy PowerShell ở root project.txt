Chạy PowerShell ở root project:

  cd "C:\My Project\e-commerce"

  Nếu dùng Docker MySQL của project:

  powershell -ExecutionPolicy Bypass -File backend-microservice\reset-demo-databases.ps1 -UseDocker -Force

  Nếu dùng MySQL local cài trực tiếp port 3306:

  powershell -ExecutionPolicy Bypass -File backend-microservice\reset-demo-databases.ps1 -Force

  Lệnh này sẽ drop sạch DB cũ, tạo lại các DB con, rồi insert data mẫu luôn.

  Sau đó chạy backend với Docker MySQL port 3307:

  powershell -ExecutionPolicy Bypass -File backend-microservice\run-all.ps1 -DbPort 3307
